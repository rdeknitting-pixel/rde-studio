# RDE “Studio”

Sito vetrina interattivo che racconta la manifattura della maglieria RDE Knitting Developers — Montagnana (PD), 100% Made in Italy.

Sito statico (HTML, CSS, JavaScript): nessuna build. Per provarlo in locale:

```bash
npx serve .
```

- `index.html` — struttura e testi (italiano)
- `js/i18n.js` — traduzione inglese
- `js/loom.js` — telaio interattivo
- `js/main.js` — animazioni e interazioni
- `assets/` — foto, clip video e logo
